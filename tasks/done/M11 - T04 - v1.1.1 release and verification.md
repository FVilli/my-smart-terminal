# M11 - T04 - v1.1.1 release and verification

## Objective
Publish the Linux installation/branding release and prove that new installs get the menu icon and scripts work.

## Constrained implementation
- Bump root/desktop/renderer version to 1.1.1 and update lockfile; update current-release references and RELEASE_NOTES/CHANGELOG.
- Build Linux `.deb`/AppImage; verify the `.deb` payload contains `smart-terminal.desktop` and the new 512x512 icon and that the package version is 1.1.1. Optionally extract/launch the packaged binary on Xvfb.
- Run focused script tests (`test:linux-install`), docs gates, unit tests, lint, typecheck/build, E2E/layout as practical; independent reviewer/evidence audit focused on `curl | sh` safety and menu integration.
- Tag `v1.1.1`, push, wait for the release workflow, verify assets and all SHA256 checksums, and confirm the install/uninstall raw URLs at the tag.
- Reconcile the gsynchro Drive copy for Markdown/image scope and leave the daemon stopped if it is still unhealthy.

## Acceptance criteria
- v1.1.1 assets include Linux AppImage/.deb (and normal macOS/Windows assets), SHA256SUMS verifies.
- `.deb` has the new icon and menu entry; install/uninstall scripts are present at the tag.
- All gates pass; release notes explain one-command install, menu icon and data preservation.
- No destructive behavior or stale version references.
